Getting Started Guide

Prepare Your CSV File (IMPORTANT!)
Your CSV file MUST include these columns with exact headers:
Required Columns:
• transaction_id - Unique identifier (e.g., TXN_001, TXN_002)
• amount - Transaction amount with currency symbol (e.g., $150.00, $2,500.50)
• merchant - Merchant/store name (e.g., "Amazon", "Walmart")
• category - Transaction category (e.g., "Electronics", "Grocery")
• timestamp - Date/time (e.g., "2025-10-09 14:30:00" or "10/09/2025")

Optional but Recommended:
• location/city - Transaction location
• card_type - Card type (Credit/Debit)
• customer_id - Customer identifier
• device - Device used (Mobile/Web/POS)

CSV Example Format:
transaction_id,amount,merchant,category,timestamp,location
TXN_001,$150.00,Amazon,Electronics,2025-10-09 14:30:00,New York
TXN_002,$2500.50,Best Buy,Electronics,2025-10-09 15:45:00,Los Angeles

✅ Max file size: 50MB
✅ Format: UTF-8 encoded CSV with comma delimiter
✅ First row MUST be headers
Upload Your Transaction Data
Navigate to the Dashboard (home page) and click the "Upload CSV File" button. Select your prepared CSV file following the format above.

What happens after upload:
• File is validated for correct format
• All transactions are analyzed using ML algorithms
• Risk scores are calculated for each transaction
• Suspicious patterns are identified
• Results are available in 30-60 seconds for most files

Common Upload Errors & Solutions:
❌ "Missing required columns" → Check your CSV headers match exactly
❌ "Invalid file format" → Ensure it's a .csv file, not .xlsx or .txt
❌ "Amount format error" → Use format like $100.00 or 100.00
❌ "File too large" → Split into multiple files under 50MB each
Configure AI Analysis (Optional but Recommended)
Go to Settings page from the sidebar menu. Configure AI-powered analysis:

1. Select Your LLM Provider:
• Gemini (Google) - Best for detailed analysis
• OpenAI (ChatGPT) - Fast and reliable
• Claude (Anthropic) - Excellent for risk assessment
• Custom - Use your own API endpoint

2. Enter Your API Key:
• Gemini: Get free key at makersuite.google.com
• OpenAI: Get key at platform.openai.com
• Claude: Get key at console.anthropic.com

3. Click "Save Settings"
Your API key is stored securely in your browser only - never sent to our servers.
Review Detection Results
After analysis completes, you'll see a comprehensive dashboard showing:

Key Metrics:

Detailed Fraud List:
Each flagged transaction shows:

Risk Score Interpretation:

CSV File Format Guide

📋 Required CSV Column Specifications
Column Name Required? Format Example Description
transaction_id REQUIRED Text/String TXN_001, TX12345 Unique identifier for each transaction
amount REQUIRED $X.XX or X.XX $150.00, 1500.50 Transaction amount with or without $ symbol
merchant REQUIRED Text/String Amazon, Walmart Store or merchant name
category REQUIRED Text/String Electronics, Grocery Transaction category or type
timestamp REQUIRED YYYY-MM-DD HH:MM:SS 2025-10-09 14:30:00 Date and time of transaction
location RECOMMENDED Text/String New York, Los Angeles Transaction location or city
card_type OPTIONAL Credit/Debit Credit, Debit Type of payment card used
customer_id OPTIONAL Text/Number CUST_12345, 98765 Customer or account identifier
device OPTIONAL Mobile/Web/POS Mobile, Web, POS Device type used for transaction
✅ Correct CSV Example
transaction_id,amount,merchant,category,timestamp,location
TXN_001,$150.00,Amazon,Electronics,2025-10-09 14:30:00,New York
TXN_002,$2500.50,Best Buy,Electronics,2025-10-09 15:45:00,Los Angeles
TXN_003,$75.25,Walmart,Grocery,2025-10-09 16:20:00,Chicago
TXN_004,$5000.00,Apple Store,Electronics,2025-10-09 17:10:00,San Francisco
❌ Common Mistakes to Avoid
1. Missing Required Columns
❌ Don't skip transaction_id, amount, merchant, category, or timestamp

2. Wrong File Format
❌ Don't upload .xlsx, .xls, or .txt files - Must be .csv

3. No Header Row
❌ First row must contain column names, not data

4. Inconsistent Data
❌ Don't mix formats: use either $100.00 OR 100.00 consistently

5. Special Characters
❌ Avoid quotes, commas inside values (use semicolon if needed)

6. Empty Rows
❌ Remove any blank rows between data
💡 Pro Tips for Best Results
1. Data Quality Matters
• Include as much detail as possible for better fraud detection
• More columns = more accurate analysis

2. File Preparation
• Save as "CSV UTF-8" format in Excel
• Test with 10-20 rows first before uploading full dataset

3. Amount Formatting
• Accepted: $1500.00, 1500.00, 1,500.00
• Use consistent decimal points (2 places recommended)

4. Date Format
• Best: YYYY-MM-DD HH:MM:SS (2025-10-09 14:30:00)
• Also works: MM/DD/YYYY, DD-MM-YYYY

5. Large Files
• For files > 50MB, split into multiple smaller files
• Upload and analyze separately, then compare results

Frequently Asked Questions

How accurate is the fraud detection?
FraudGuard Pro uses advanced machine learning algorithms that achieve 99.8% accuracy in fraud detection. Our models are trained on millions of real-world transactions and continuously updated to identify emerging fraud patterns.
What file formats are supported?
Only CSV (Comma-Separated Values) files are supported. Your CSV must include specific headers and columns. See the "CSV File Format Guide" section above for detailed specifications. Maximum file size is 50MB. Excel files (.xlsx, .xls) must be saved as CSV format before uploading.
What CSV columns are absolutely required?
Required columns (must have these exact names):
• transaction_id - Unique transaction identifier
• amount - Transaction amount (e.g., $150.00)
• merchant - Merchant or store name
• category - Transaction category
• timestamp - Date and time

Without these columns, the system cannot analyze your data. Click "Download Template" in the CSV Format Guide section to get a properly formatted example file.
How do I get an API key for AI analysis?
For Google Gemini: Visit Google AI Studio and create a new API key.

For OpenAI: Sign up at OpenAI Platform and generate an API key from your account dashboard.

For Claude: Visit Anthropic Console to get your API key.
Is my data secure?
Yes! All data is processed locally on your server and encrypted during transmission. We never store your transaction data permanently. API keys are stored in your browser's local storage and never transmitted to our servers.
Can I export the analysis results?
Absolutely! You can export all analysis results including fraud detection reports, AI insights, and analytics data in various formats (CSV, JSON, PDF) from the Analytics page.
What makes a transaction suspicious?
Our ML models look for multiple fraud indicators including: unusual transaction amounts, geographic anomalies, velocity patterns (too many transactions in short time), mismatched merchant categories, and behavioral deviations from normal user patterns.
How often is the fraud detection model updated?
Our core fraud detection models are updated quarterly with the latest fraud patterns and techniques. The AI analysis powered by LLMs stays current automatically as providers update their models.
Why am I getting "Missing required columns" error?
This error occurs when your CSV file doesn't have the required column headers. Make sure your first row contains these exact column names (case-sensitive):
transaction_id, amount, merchant, category, timestamp

Common issues:
• Column names have extra spaces (e.g., "transaction_id " with trailing space)
• Different naming (e.g., "txn_id" instead of "transaction_id")
• Missing header row entirely

Download our CSV template to get the correct format.
How long does analysis take?
Fraud Detection: 30-90 seconds for most files
• Small files (< 1,000 transactions): ~30 seconds
• Medium files (1,000-10,000): ~60 seconds
• Large files (10,000-100,000): ~90 seconds

AI Analysis: 10-30 seconds additional
Analysis time depends on number of fraud cases detected and your selected LLM provider.
Can I analyze multiple files?
Yes! You can upload and analyze multiple files. Each file gets a unique task ID. Results are saved and accessible from the Analytics page. You can switch between different analysis results by uploading new files. Previous results remain available until you clear your browser data.
What happens to my data after upload?
Privacy First:
• All processing happens locally on your server
• Data is temporarily stored during analysis
• Results are saved in local storage (your browser)
• No data is transmitted to external servers except when you use AI analysis (sent directly to your chosen LLM provider with YOUR API key)
• You can delete results anytime by clearing browser data

We never store, share, or have access to your transaction data.
